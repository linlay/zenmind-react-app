# Worklets pnpm Realpath Bundle Mode Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent pnpm peer-suffix paths from making Reanimated worklets import `react-native` inside a Worklet Runtime.

**Architecture:** Commit a minimal pnpm patch for the installed Worklets Babel plugin and register it in the app manifest. Apply the patch to an in-memory copy of the real Babel plugin so the regression test verifies generated closure/import behavior without modifying `node_modules` or requiring a platform-specific `patch` command.

**Tech Stack:** Node.js `node:test`, Babel 7, pnpm patched dependencies, React Native Worklets 0.8.3.

### Task 2: Add and register the dependency patch

**Files:**

- Create: `patches/react-native-worklets@0.8.3.patch`
- Modify: `package.json`

**Interfaces:**

- Consumes: Worklets plugin `isAllowedForRelativeImports(filename, workletizableModules)`.
- Produces: boundary-aware `isModulePath(filename, moduleName)` behavior and app-level pnpm patch registration.

- [ ] **Step 1: Add the minimal plugin patch**

The patched helper must normalize Windows separators and require a path boundary:

```js
function isModulePath(filename, moduleName) {
  const normalizedFilename = filename.replace(/\\/g, '/');
  const modulePath = `/${moduleName}`;
  return (
    normalizedFilename.includes(`${modulePath}/`) ||
    normalizedFilename.includes(`${modulePath}.`) ||
    normalizedFilename.endsWith(modulePath)
  );
}
```

`isAllowedForRelativeImports` must call this helper for `alwaysAllowed` and `workletizableModules`.

- [ ] **Step 2: Register the patch in `package.json`**

Add:

```json
"pnpm": {
  "patchedDependencies": {
    "react-native-worklets@0.8.3": "patches/react-native-worklets@0.8.3.patch"
  }
}
```

- [ ] **Step 3: Run the focused test and verify GREEN**

Run the focused command from Task 1. Expected: all plugin patch tests pass.

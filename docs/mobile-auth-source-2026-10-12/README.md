# 移动端账号电脑与默认云端 Token 改造执行大纲

建档日期：2026-10-12。状态：**代码实施及本地检查已完成，真实服务与真机验收进行中**。

本期实现两条独立访问路径：账号登录后查询和访问所属电脑；默认云端使用自己的 Token，无需先登录账号。两条路径复用现有来源选择、聊天同步、SQLite 和电脑应用链路。**绝对不允许过度设计。**

本目录是后续工作的执行入口。与 [2026-10-09 计划](../account-source-ui-2026-10-09/README.md) 重叠的登录、默认云端、来源与缓存要求，以本目录为准；旧计划保留历史证据及范围外工作。文档中的目标不代表代码已实现，静态核实不代表真实服务可用。

## 已确认目标

| 项目         | 本期行为                                                                |
| ------------ | ----------------------------------------------------------------------- |
| 账号登录     | 查询当前账号有效电脑及在线状态，选择所属电脑进行已有对话与工作          |
| 默认云端     | 对应原默认数据源；独立使用 Token，不要求 Identity 账号登录              |
| 配置凭证     | 没有用户保存凭证、且未主动退出云端时，优先尝试已有配置凭证              |
| 手动 Token   | 支持输入/粘贴；验证成功后保存，按默认来源绑定，下次启动验证恢复         |
| 凭证失效     | 手动 Token 明确认证失效时引导登录，不悄悄回退配置凭证；网络失败保留凭证 |
| 云端不可用   | “云端”文字置灰，来源行不可选择；另有可点击的登录或重试入口              |
| 使用中断线   | 保留云端选择及缓存，禁止发送与其他远端操作，恢复验证成功后启用          |
| 离线电脑     | 保留选择与所属缓存入口，禁止新对话及远端操作；无缓存显示空态            |
| 设备查询失败 | 保留已知列表，标明刷新失败，不当作全部离线或撤销                        |
| 电脑撤销     | 停止访问、隐藏失效内容并显示引导，用户选择其他来源，不自动回落云端      |
| 启动恢复     | 优先恢复上次选择；首次验证默认云端，成功才进入，否则显示登录/选择引导   |
| 独立退出     | 退出账号只释放电脑访问；退出默认云端只释放云端访问，互不影响            |
| 主动退出云端 | 不自动使用配置 Token 重新进入，直到用户主动登录                         |
| 工作能力     | 沿用已有聊天、附件、模型设置及打开电脑应用；不新增应用启动/暂停能力     |

## 最小架构与执行约束

**变更直接了当，职责清楚，无冗余代码逻辑，绝对不允许过度设计。** 每项代码变更必须对应已确认目标或有证据的接口缺口。

1. 先验证、再修改。已有能力通过验收即可关闭，不为任务清单而造代码。
2. 账号会话只管理电脑访问；默认云端凭证只管理默认源访问。不得复制第二套聊天模型、同步服务或业务 Provider。
3. 来源选择只有一个真源，最小表达云端、电脑、暂无可用来源；扩展既有选择和订阅，不并排增加 store 或页面镜像。
4. 页面负责 UI；core 处理凭证与 transport；feature service 协调选择、缓存和连接；业务写入仍走 chatSyncService / chatRepository。
5. SQLite 保持聊天真源，MMKV 延续目录快照及既有设置用途。凭证不写入业务 ID、数据库名称、日志或任务文档。
6. 复用 sharedWsTransport、现有 API 和 WebApps runtime。探测不创建专用 Socket 池，不影响当前电脑连接；来源切换不取消远端任务。
7. 业务验证复用现有只读请求，不能直接调用会写库的首页刷新，也不能用 Socket onopen 或聚合状态证明云端可用。
8. 不新增通用状态机、权限引擎、来源插件注册表、同步引擎、后台轮询系统、凭证加密框架或缓存迁移框架；必要状态只覆盖已确认场景。
9. 替换时清理被替代的调用、重复状态、闲置代码和仅服务旧逻辑的测试，不长期保留新旧两条可达运行路径。
10. 默认不新增依赖、不改服务端 schema、不改无关 UI。确需依赖时只改 package.json，禁止安装及改 lock，交由用户手动执行。

## 云端可用性口径

只有使用当前凭证完成现有聊天目录请求，并通过响应校验，才允许选择云端；空目录也算成功。明确认证失败、权限不足、网络故障和响应协议异常分别反馈，不把所有失败导向登录。

| 状态                   | 来源行                   | 对话与恢复             |
| ---------------------- | ------------------------ | ---------------------- |
| 检测中                 | 灰态，不可选择           | 显示检测状态           |
| 验证通过               | 正常可选                 | 正常对话               |
| 缺凭证 / 明确认证失效  | 灰态，不可选择           | 独立 Token 登录引导    |
| 网络 / 服务 / 协议失败 | 灰态，不可选择           | 原因与重试；保留凭证   |
| 明确无权限             | 灰态，不可选择           | 权限说明；不误删凭证   |
| 当前云端断线           | 保留当前选择，来源行灰态 | 只读缓存，远端操作禁用 |

验证触发点为启动恢复、用户刷新、提交 Token 和断线恢复；复用既有重连机制，有界超时、取消和迟到结果失效，不增加持续轮询。界面状态可由小型类型和既有订阅表达，无需状态机库。

## 验收与完成口径

- 仅 Token、仅账号、两者有效、两者均不可用四种组合均符合入口和权限边界。
- 两种退出互不影响；退出云端后配置凭证不自动复活，换 Token 不串缓存、不重放旧 outbox。
- 离线与失败只影响对应来源；撤销电脑隐藏失效内容，云端不可用时不强行回落。
- 对话、搜索、详情、资源、上传、导出和应用跟随当前来源；既有不支持能力仍有明确空态。
- 切源、退出、换凭证和异步迟到结果不串数据，已提交远端任务继续执行。
- 真实默认源、账号电脑及 iOS/Android 验收与相关本地检查均有证据；mock 或 Web 导出不能替代真实验证。

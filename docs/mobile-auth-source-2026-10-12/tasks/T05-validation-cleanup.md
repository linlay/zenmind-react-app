## 验收矩阵

| 场景                 | 必须证明                                                                          |
| -------------------- | --------------------------------------------------------------------------------- |
| 仅云端 Token         | 无 Identity 会话也能使用默认源；电脑区域有账号登录引导                            |
| 仅账号               | 能查看和选择所属电脑；不可用云端灰态，Token 登录仍可达                            |
| 两者有效             | 云端与电脑主动切换，业务和缓存不串源，两种退出互不影响                            |
| 两者不可用           | 停在准确引导，无业务连接或失效内容泄露                                            |
| Token 恢复/更换/退出 | 缓存按账号和来源隔离，切源使迟到回调失效；不自动重发 query，不迁移或认领旧聊天数据；认证、来源配置、远端数据和用户原始文件保留。 |
| 云端连接故障         | 凭证保留，已选缓存只读，发送禁用；恢复验证后才启用                                |
| 目录为空 / 权限不足  | 空目录有效；权限不足有准确原因，不误删凭证                                        |
| 电脑离线 / 查询失败  | 缓存可读，远端操作禁用；失败不清列表或误判撤销                                    |
| 电脑撤销 / 账号失效  | 停止访问、隐藏内容、显示引导，不自动跳云端或其他电脑                              |
| 异步与长任务         | 换 Token、切源、退出后的迟到结果无效，已提交远端任务继续                          |
| 数据面与应用         | 对话、搜索、详情、资源、上传、导出、通知定位和 WebApps 均按所属来源及既有能力工作 |

## 必须遵守的决策

1. 手机不跳转官网、不使用登录 WebView，不增加 OAuth 授权码、PKCE、App 登录回调或 Universal Link。
2. 官网认证结果只用于识别用户和授权电脑；Identity 票据用于对应 Platform 业务连接。两者名称、存储、传输和校验分开。
3. Hub 的 `SSO_JWT_USER_ID_CLAIM` 是用户 ID 的权威配置；不让 `account_id` 自动覆盖它，不按品牌硬编码字段。
4. Identity 票据来自 Desktop 既有 `issueAccessToken`；Hub 不签发、不把票据入库，不新增 `tr_` 或另一套票据作为必经路径。
5. 同用户多台电脑各自有票据；Hub 电脑注册 ID 与本地 Identity 设备 ID 分开。
6. Hub 服务端检查当前用户是否拥有目标电脑，列表过滤不能代替连接和 HTTP 请求授权。
7. 新凭据接入复用既有 accountAuth、service、sharedWsTransport 和来源生命周期；删除被替代路径，不建设认证工厂、通用状态机或新旧双轨框架。
8. 现有合法登录入口不凭本计划自动删除。误接 Identity 的公网账号入口不继续保留为隐式回退；其替换/撤除由 T00、T06 逐项核实。

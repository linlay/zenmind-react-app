# T07 集成验收、发布与清理

[返回总览](../README.md)

状态：**阻塞**。前置：[T01](T01-contract-readiness.md)–[T06](T06-email-login-ui.md)。

## 目标与范围

复用前六项完成真实闭环、必要回归、灰度与回滚验证，交付可追溯结果。本任务验证和接线，不重新实现验证码、认证、页面或发布平台。

## 必须完成

1. SMTP host/port、TLS、认证、发件地址/名称、发送权限、额度与超时配置到位；固定中英双语纯文本正文核实。使用确认的测试账号完成密码登录 → 绑定 → 退出 → 邮箱验证码登录 → 解绑 → 新邮箱地址绑定。
2. 校验邮箱验证码登录与密码同 accountId、username 和权限，deviceId/deviceToken 格式一致；重启恢复、刷新、退出、电脑目录/选择和既有云端 Token 正常。
3. 验证一对一竞争、三用途隔离、单码消费、错 5 次、有效期、重发成功/失败/未知、跨请求累计限制和重启后限制保留。解绑/重绑后旧码不能登录或解绑。
4. 验证注销/账号切换/页面离开拒绝迟到响应，查询失败不显示未绑定；解绑保留当前与其他设备已有会话。管理员人工解绑有鉴权、原因、确认、审计和旧挑战失效。
5. App 根据改动执行 pnpm typecheck、pnpm lint、相关/全量现有测试及必要 pnpm build；Identity 执行既有 Go/管理台检查。检查只跑所需范围，失败修复后再扩大，不写机械复刻实现的测试。
6. 真机核实验证码填充/粘贴、键盘、返回、safe area、弱网与前后台倒计时。目标平台按现有发布范围覆盖；缺设备或未开通供应商要明确未验证项，不能算完成。
7. 先部署兼容后端并关闭新入口，执行迁移和服务烟测，再发布 App；绑定与邮箱验证码登录按两个现有配置启用。未启用时给出明确不可用反馈，不增加远端配置拉取体系。
8. 灰度观察发送/验证结果、限流、服务错误和费用，复用已有日志/监控；不为本次建运营仪表盘。公开 API 和调试日志无完整邮箱地址、验证码或 Token。
9. 回滚关闭新增绑定及邮箱验证码登录，保留密码登录、数据、解绑和人工处理；不通过回滚删除绑定/审计表或撤销全部既有会话。后端回退须确认新旧 schema 兼容，不承诺无验证的降级。
10. 验证个人和企业邮箱、大小写变体、点号/+tag 保留、完整地址展示与日志脱敏。覆盖 SMTP 接受/拒绝/超时、垃圾邮件和延迟投递；未收到时手动重发，旧邮件晚到不能复活旧码，不增加自动重试或投递追踪。

## 防止过度设计

不新增 CI/发布编排产品、监控平台、多实例方案、通用负载测试框架或本次无关的迁移兼容层。测试应验证用户结果、并发约束和可信边界；文档中的任务数不能成为重复实现的理由。

## 完成标准

- 七项实际改动、已删除冗余代码、测试输出、真实邮件/真机证据和人工处理流程均有记录。
- 未知邮箱地址响应、迟到结果、额度与发送不明情况已验证，服务商接入不再是占位。
- 密码/QR/云端、电脑目录与原会话生命周期回归通过；真实验收缺口已完成，不只通过 mock 或 Expo export。
- 总览和子任务状态同步；业务入口、模块职责和运行链路变化写入实际 `.doc/curated`，运行 xgraph index/status，按仓库约定 sync/finish。
- 原有用户改动保留，临时配置/凭证/代理/生成物全部审计；剩余项必须记录原状、风险与修复命令，未完成清理不标整体完成。

# T04 手机登录会话与来源生命周期

保留密码和扫码两种账号登录。Identity 返回统一认证会话及持久设备凭据；删除设备类型和三档信任输入/响应。扫码只含 challengeId，领取密钥留在新登录页面内存，已登录账号从账号设置页确认。

设备管理及来源抽屉仅展示 Hub Desktop 目录。保留单飞刷新、auth generation、账号/来源隔离、离线缓存选择、来源切换协调与迟到请求失效。

手机 JWT 仅发送到配置的 Identity 和 Hub origin。云端沿用现有 authMode/accessToken，不将本地账号分区当作云端服务端隔离。手机退出不退出 Desktop、不取消远端任务。

验收：两种登录、恢复与刷新、临时故障保留凭据、确认失效清除凭据、退出期间迟到响应、云端凭据边界、离线来源与缓存协调。相关改变不触及聊天持久化模型。

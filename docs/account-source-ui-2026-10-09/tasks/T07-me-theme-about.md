## 最小变更

1. 顶部账户卡显示账号登录状态：未登录为头像/未登录/箭头；登录后为账号名称与账户入口，不展示扫码配对身份。
2. 一级保留账户、主题、语言、存储空间、设备管理、关于；连接地址、设备 ID、有效期等进入设备详情，开发工具/演示进入开发设置。
3. 主题在用户页使用系统/浅色/深色分段选择，直接调用现有 setThemePreference；删除被替代的重复主题操作入口。
4. 复用已有语言、存储清理与设备管理能力，必要时只调整二级路由或分组，不顺手重写设置系统。
5. 新增最小 AboutScreen 和 route，迁移产品名/版本/开发态版本三连点；用户信息与设置逻辑不塞进关于页。
6. 继续使用现有蓝色强调、主题 token、共享 Header 和行组件；分组可参考浅灰画布/白色表面，不新建全局视觉体系。
7. 文案走 shared-i18n，一级 Header 固定，内容按实际 safe area/tab bar 避让。

## 不做与禁止扩展

- 不加入套餐、积分、字体大小、朗读、触感、记忆库等未要求功能。
- 不建立通用设置 schema/渲染器、账户中心框架或新主题 Provider。
- 不在页面读写 MMKV，不复制 theme 状态，不保留两套重复主题配置 UI。
- 不给每个分组增加阴影，不修改未要求的全局颜色和字号。
- 既有二级页能承载的内容，不额外拆出只有一行的页面。
